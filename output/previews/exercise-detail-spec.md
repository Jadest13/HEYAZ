# HEYAZ 운동 상세 모달

운동 계획과 AI 코치의 운동 항목에서 같은 모달을 연다. 긴 설명을 기본 목록에서 분리하고, 사용자가 운동을 수행할 때 필요한 정보부터 보여준다.

| 영역 | 표시할 정보 | 데이터 기준 |
| --- | --- | --- |
| 제목 | 운동 이름, 근력/시간/유산소 구분, 장비 | 운동 카탈로그 또는 직접 추가한 운동 |
| 자극 부위 | 주요 부위, 보조 부위 | 운동별 가이드. 첫 부위를 주요 부위로 표시 |
| 이번 계획 | 세트, 횟수 또는 시간, 중량, 세트 사이 휴식 | 사용자가 클릭한 계획/제안의 값 |
| 수행 방법 | 준비 → 동작 → 복귀의 짧은 3단계 | 운동별 설명, 공개 운동 라이브러리 참고 |
| 자세 체크 | 흔히 놓치는 자세 한 가지, 호흡·통증 안내 | 일반적인 수행 안내 |
| 유산소 추가 정보 | 사용자 체중, 계획된 운동 시간, 예상 소모량 범위 | 현재 프로필 체중 × 시간 × MET 기반 추정 |
| 최근 기록 | 최근 3회 날짜, 완료 세트·횟수/시간, 최고 중량 | 실제 저장 기록. 예시 기록에는 별도 표시 |
| 함께 살펴볼 운동 | 관련 운동 상세로 이동 | 계획을 자동 교체하지 않음 |
| 참고 | NASM 운동 라이브러리, Mayo Clinic 근력 운동 안내 | 모달 안에서 원문 링크 제공 |

## 동작

- 운동 목록에서는 이름·자극 부위 요약·계획 수치만 표시한다.
- 클릭하면 모달을 열고 포커스를 모달 안으로 옮긴다. 배경 스크롤을 잠근다.
- 닫기, Escape, 배경 클릭으로 닫는다. 닫은 후 원래 운동 항목으로 포커스를 돌려준다.
- 모바일에서는 1열로 배치하고 제목·닫기 버튼을 상단에 유지한다.
- 기록이 없으면 빈 상태를 표시한다. 사용자 추가 운동에 수행 가이드가 없으면 만들어낸 설명을 표시하지 않는다.
- 시안의 구성을 반영해 자극 부위 개략도와 계획 수치 타일을 나란히 표시한다. 자극 부위는 운동 카탈로그에 맞춰 전면·후면 그림에 강조한다. 벤치프레스에는 동작 개략도를 함께 표시한다.
- 3단계 수행 방법과 최근 3회 기록은 넓은 화면에서 가로 카드, 모바일에서 세로 카드로 배치한다.
- 하단의 ‘확인했어요’ 버튼으로 닫을 수 있다. 관련 운동으로 이동하면 모달 내부 스크롤을 맨 위로 돌린다.

## 운동 계획

- 주간/월간과 탭/카드 보기 전환을 제거한다. 주간 날짜 줄과 선택한 날의 루틴을 기본 화면으로 고정한다.
- 이전 주, 다음 주, 오늘 이동과 날짜 키보드 선택을 유지한다.

## AI 코치 정보 밀도

- 주간 생성: 주간 합계 + 요일별 요약. 기본 접힘, 펼치면 운동 목록.
- 하루 생성: 해당 요일만 표시. 운동 목록은 기본 펼침, 운동 클릭 시 상세 모달.
- 수정/추가: 변경되는 요일과 운동만 표시. 추가는 앞뒤 운동 또는 시작/끝 위치를 명시.
- 수치 변경: 해당 운동의 변경 전후 수치만 표시.
- 적용 전 기존 계획과 기록은 유지하고, 최신 계획 버전과 다르면 재제안을 요청한다.

## 신체 변화

- 여러 지표는 기본적으로 첫 측정 대비 변화율(%)로 비교한다.
- 실제 값 모드에서는 지표마다 독립적인 축의 그래프를 표시한다. 축이 다르므로 그래프 높이를 직접 비교하지 않도록 설명한다.
- 마우스 이동, 날짜 포커스, 날짜 터치로 해당 날짜의 네 가지 실제 측정값을 보여준다. 누락값은 '미측정'이다.
- 변화율 기준이 0이면 계산하지 않고 안내한다. 누락 구간을 임의로 연결하지 않는다.

## Burning Day

- 목록: 월 필터, 최근 날짜 우선, 6개씩 표시, 더 보기.
- 리포트: 완료율 / 예상 운동 시간 / 예상 소모량을 상단에 배치.
- 완료·일부 완료·스킵은 작은 상태 칩으로 요약.
- 회차별 상세는 기본 접힘, 상태별 필터 제공.
